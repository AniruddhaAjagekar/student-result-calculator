# 🎓 Student Result Calculator

## 📌 Project Overview

Student Result Calculator is a simple and responsive web application developed using HTML, CSS, and JavaScript. The application allows users to enter marks for five subjects and automatically calculates the total marks, percentage, grade, and pass/fail status.

This project was developed with the assistance of Claude AI as part of the AI-Assisted Web Application Development assignment.

---

## 🚀 Features

- Input marks for 5 subjects
- Validate marks between 0 and 100
- Calculate total marks
- Calculate percentage
- Display grade based on percentage
- Show Pass/Fail status
- Responsive and user-friendly interface
- Instant result generation

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 📊 Grading System

| Percentage | Grade |
|------------|--------|
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| Below 60 | F |

---

## ✅ Pass/Fail Criteria

- PASS: Percentage ≥ 40%
- FAIL: Percentage < 40%
